- [LaravelVerifactu](https://github.com/squareetlabs/LaravelVerifactu) - Paquete Laravel para gestión y registro de facturación electrónica VeriFactu.
- [verifactu (jdgOpenCode)](https://github.com/jdgOpenCode/verifactu) - Librerías PHP adicionales para el sistema VeriFactu.
- [verifactu-api-php](https://github.com/EduardoRuizM/verifactu-api-php) - API PHP para facturas VeriFactu con envío a la AEAT.
- [verifactu-api-python](https://github.com/EduardoRuizM/verifactu-api-python) - API Python para facturas VeriFactu con envío a la AEAT.

- [verifactu-delphi-demo](https://github.com/seccion31/verifactu-delphi-demo) - Demo de alta y anulación de factura VeriFactu en Delphi.

- [FacturaE](https://github.com/carlosga/FacturaE) - Firma electrónica de facturas FacturaE en C# puro.

- [FaceWebServiceClient](https://github.com/xocapik/FaceWebServiceClient) - Cliente .NET para el servicio web de FACe (Punto General de Entrada de Facturas Electrónicas de la AGE).

- [gobl.ticketbai](https://github.com/invopop/gobl.ticketbai) - Convierte documentos GOBL al formato TicketBAI en Go.
- [verifactu-xmlgen](https://github.com/binovo/verifactu-xmlgen) - CLI para crear ficheros TicketBAI y VeriFactu.
- [pytbai](https://github.com/codesyntax/pytbai) - Crea, gestiona y envía facturas TicketBAI a las autoridades fiscales vascas en Python.
